# 书架快速检索 — 文件变更清单

> 所属模块: SHELF-001 (书架管理) | 版本: v1.3.2 | 状态: 更新反映 v1.2/v1.3 已完成变更 + v1.3.2 搜索触发方式调整

## 阶段一：核心变更（✅ v1.2 已完成）

以下表格列出了实现书架内嵌搜索栏已完成的所有文件变更：

| 文件路径 | 变更类型 | 变更说明 |
|------|------|------|
| frontend/src/views/ShelfView.vue | 修改 | 在书架标题行与书籍列表之间新增搜索输入框组件。添加搜索相关的响应式状态变量（searchKeyword、aiSearchMode、aiSearchResults、filterTab、debounceTimer）。实现 onSearchInput 防抖函数和 performSearch 搜索执行函数。新增 AI 模式切换按钮和进度提示。书籍列表的渲染数据源从 booksStore.books 切换为 displayBooks（计算属性，根据搜索/筛选状态自动切换 allBooks/filteredBooks/books）。新增 highlightMatch 方法实现搜索结果高亮。**v1.3.2**：移除 300ms/800ms 防抖定时器，新增「搜索」按钮（AI 模式显示「AI 搜索」）+ Enter 触发；新增 appliedKeyword/appliedAiQuery 区分输入词与已生效词，编辑关键词后旧结果立即失效；高亮/空状态/提示文案基于已生效词渲染。 |
| frontend/src/stores/books.ts | 修改 | 新增三个响应式状态：allBooks 全量书籍缓存数组、filteredBooks 客户端过滤后的展示数组、searchMode 当前搜索模式标识。新增 isClientMode 计算属性。新增 fetchAllBooks 方法用于一次性加载全量数据（page_size=200），自动判断是否需要切换为服务端搜索。新增 clientSearch 方法用于客户端双字段过滤。新增 clientFilter 方法支持关键词+多条件组合筛选。新增 resetFilter 方法恢复全量书架。增删改操作同步维护 allBooks 和 filteredBooks 缓存。 |
| frontend/src/api/books.ts | 修改 | 无需新增 API 调用，现有 getBooks 函数（支持 page_size 参数）复用。v1.3 新增 aiSearchBooks 函数调用 POST /api/v1/ai/search。 |
| backend/app/services/book_service.py | 修改 | search_books 方法的查询条件从单一的 title LIKE 扩展为 title LIKE OR author LIKE 的双字段搜索（使用 SQLAlchemy or_ 函数）。 |
| backend/app/api/v1/books.py | 无需修改 | 现有的 GET /api/v1/search 端点接口签名无需变更，因为 q 参数同时用于书名和作者搜索。 |
| backend/app/api/v1/ai.py（v1.3 新增文件） | 新增 | 定义 POST /api/v1/ai/search 与 POST/GET /api/v1/ai/summary/{book_id} 三个 AI 端点。 |

以下表格列出了实现 Ctrl+K 命令面板已完成的文件变更：

| 文件路径 | 变更类型 | 变更说明 |
|------|------|------|
| frontend/src/components/CommandPalette.vue | 新增 | 创建命令面板组件。使用 el-dialog 作为弹出容器（无 header、圆角 12px、顶部 15vh）。包含搜索输入框（自动聚焦）和搜索结果列表。实现键盘导航逻辑（ArrowDown/ArrowUp 选择、Enter 跳转到阅读器、Esc 关闭）。接入 booksStore.allBooks 进行客户端实时过滤。无输入时展示最近阅读的书籍列表（localStorage 持久化，最多 5 本）。搜索高亮使用正则替换 + HTML escape。底部显示快捷键提示。面板关闭时自动清空状态。 |

## 变更注意事项

1. ✅ ShelfView.vue 是变更最密集的文件，集成了搜索栏、筛选、AI 模式切换、高亮、空状态等功能；v1.3.2 起搜索由按钮/Enter 触发（已移除防抖）。未来可考虑抽取搜索逻辑为 composable。
2. ✅ 修改 Pinia Store 时保持向后兼容——现有的 books 数组和 fetchBooks 方法的签名和行为未改变，其他页面（SearchView.vue、BookDetailView.vue）不受影响。
3. ✅ 后端 search_books 方法的改动使 q 参数同时匹配书名和作者。API 文档（v1.3 版）中已补充双字段搜索说明。
4. ✅ CommandPalette 组件在对话框打开时按需调用 fetchAllBooks（若 allBooks 为空）。
5. ✅ 快捷键 Ctrl+K 在 input/textarea 聚焦时不拦截，避免与浏览器地址栏（Chrome/Edge）和搜索框冲突。
