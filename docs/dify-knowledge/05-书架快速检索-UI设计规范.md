# 书架快速检索 — UI 设计规范

> 所属模块: SHELF-001 (书架管理) | 版本: v1.3 | 状态: 更新反映 v1.2/v1.3 实现

## 书架页面搜索栏布局（v1.2 已实现）

搜索栏位于书架标题行与书籍列表之间，视觉层次如下（从上到下）：
1. 第一行：左侧"我的书架"标题和书籍总数统计，右侧"添加小说"按钮
2. 第二行：搜索输入框行，左侧搜索输入框占据主要宽度，右侧普通/🤖 AI 语义搜索模式切换（el-radio-group）
3. 第三行：AI 搜索进度提示（仅 AI 搜索中显示，含动画点 + "AI 正在理解…"文字）
4. 第四行：快捷筛选标签（全部、已标记、抓取完成、有 EPUB），以单选按钮组形式排列。AI 搜索模式下隐藏
5. 第五行起：书籍卡片列表

## 搜索输入框规格（v1.2 已实现）

- 组件类型：Element Plus 的 el-input 组件
- 尺寸：large（大尺寸），确保在移动端也有足够的触摸区域
- 图标：输入框前缀显示 Search 图标
- 清空按钮：输入框后缀显示清除按钮，点击后立即恢复全量书架
- 占位符文字：普通模式为"搜索书名或作者…"，AI 模式为"用自然语言描述你想找的书…"
- 输入行为：输入过程中不立即搜索，等待用户停止输入 300 毫秒后触发
- 最小触发长度：输入至少 2 个字符后才触发搜索
- 搜索模式切换：el-radio-group 按钮组，普通 / 🤖 AI 语义
- AI 搜索中状态：输入框禁用 + 显示进度动画（三点跳动 + 提示文字）

## 命令面板规格（v1.2 已实现）

命令面板通过 Ctrl+K（Mac 为 Cmd+K）快捷键唤起。面板规格如下：
- 容器：Element Plus 的 el-dialog，宽度 560 像素，顶部偏移 15% 视口高度
- 不显示关闭按钮（el-dialog header 通过 CSS 隐藏），用户通过 Esc 键或点击遮罩层关闭
- 搜索输入框自动获取焦点并全选文本
- 无输入时显示"最近阅读"区块，列出最近在阅读器中打开过的书籍（localStorage 持久化）
- 有输入时（≥2 字符）实时客户端过滤匹配结果
- 每条结果显示书籍图标（📖 emoji）、书名、作者名，已标记书籍显示 ★
- 如有章节则显示章节数标签
- 当前选中项高亮显示（accent-ice-soft 背景色），支持鼠标悬停和方向键切换
- 底部快捷键提示：↑↓ 导航 / Enter 打开 / Esc 关闭
- 无结果时显示"书架中未找到匹配 … 的书籍"
- 搜索关键词以暖黄色高亮标记（#fff3cd 背景 + #856404 文字）
- 面板关闭时自动清空搜索词和选中索引

## 空状态设计（v1.2 已实现）

当搜索无结果时，显示以下内容：
- 一个搜索图标（SVG 圆形+斜线）
- 提示文字："未找到匹配 [用户输入的关键词] 的书籍"
- 副提示："试试其他关键词，或检查拼写是否正确"
- 两个操作按钮："清除搜索"清空输入框恢复书架、"去外部搜索"跳转到 SearchView

## 移动端适配

- 搜索栏在窄屏幕（宽度小于 768 像素）下占满整行宽度
- 筛选标签在窄屏幕下可以横向滚动
- 命令面板在窄屏幕下宽度自适应（最大 95% 视口宽度）
- 搜索输入框的触摸区域高度不小于 44 像素（符合 iOS/Android 推荐标准）

## 配色与样式（v1.2 已实现）

搜索栏和命令面板遵循 App 既有的冷色调（深蓝和石板灰）设计语言：
- 搜索框背景色使用 Element Plus 默认样式
- 搜索框聚焦时边框使用 Element Plus 默认聚焦样式
- 搜索结果高亮项背景色使用 --accent-ice-soft 变量
- 命令面板内匹配文本的高亮标记使用暖黄色（#fff3cd 背景 + #856404 文字）
- 星标颜色：#c9a96e（冷调金色）
- 命令面板底部快捷键提示使用 --border 背景 + --muted 文字色
- AI 匹配信息行：score 百分比 + match_reason 文字，使用 --muted 色
