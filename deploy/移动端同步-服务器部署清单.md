## 步骤 4 · AI 依赖（Dify）检查（服务器上）

```bash
grep -i dify /opt/novel-backend/backend/.env || echo "未配置 Dify"
```

- 未配置 `dify_api_url` / `dify_api_key` / `dify_recommend_api_key` 时：
  - AI 语义搜索、AI 摘要会失败；AI 题材推荐前端会**回退为直接全网搜索**（可用但非智能推荐）。
- 如需完整 AI 功能，在 `/opt/novel-backend/backend/.env` 补上 Dify 配置后重启：
  ```bash
  # 编辑 .env 追加：dify_api_url=... / dify_api_key=... / dify_recommend_api_key=...
  systemctl restart novel-backend
  ```
- 若暂不需要 AI，可跳过本步（其余功能不受影响）。

## 步骤 6 · 端点验证（任意机器，期望值见注释）

```bash
B=http://47.120.49.238/api/v1
curl -s -o /dev/null -w "ranking/sources     -> %{http_code}\n" $B/ranking/sources           # 401（存在，需鉴权）
curl -s -o /dev/null -w "crawl-stream        -> %{http_code}\n" $B/books/x/crawl-stream      # 期望 401/403（此前 404）
curl -s -o /dev/null -w "cover               -> %{http_code}\n" $B/books/x/cover             # 期望 401（此前 404）
curl -s -o /dev/null -w "import(POST)        -> %{http_code}\n" -X POST $B/books/import      # 期望 401/422（此前 405）
curl -s -o /dev/null -w "ai/recommend(POST)  -> %{http_code}\n" -X POST $B/ai/recommend      # 期望 401/422（此前 404）
curl -s -o /dev/null -w "CORS preflight      -> %{http_code}\n" -X OPTIONS $B/books \
  -H "Origin: http://localhost" -H "Access-Control-Request-Method: GET"                     # 200
```

判定：`crawl-stream`/`cover`/`ai/recommend` 不再是 404、`import` 不再是 405 → 后端已同步到最新。

## 步骤 7 · 移动端安装与真机手测（你在手机上）

- 最新 APK：仓库根目录 `novel-manager-v1.0-debug.apk`（SHA256 `C968BAA2…`，2026/9/22 重建；真机手测已通过）。
  本版新增：① 移动端下载改走 Capacitor Filesystem 落盘到 Documents 目录
  （Android WebView 不支持 blob 下载，旧版点下载无反应）；② 本地导入/下载前用原生
  `Environment.isExternalStorageManager()` 检测真实「所有文件访问」状态（Android 13+
  旧逻辑会误报已授权导致扫描静默空结果），未授权时显示「去系统设置开启」按钮
  直达开关页；③ 原生返回键优先在 SPA 历史内回退（旧版详情页按返回直接退出 App）。
- 真机手测清单（这些是原生专属、无法在浏览器验证的项）：
  1. 本地导入：未授权时应弹出「未获得存储权限」提示（Android 13+ 也能正确检测），点「去系统设置开启」直达本应用「所有文件访问」开关页，开启后返回 App 再点扫描。
  2. 本地导入：能扫描到设备内 .txt/.epub 并成功导入。
  3. 详情页：封面正常显示（依赖 `cover` 接口）。
  4. 下载 EPUB/TXT：未授权时提示并引导去设置页；已授权时文件保存到设备 Documents 目录（成功提示显示保存路径，可在「本地导入」扫描中见到该文件）。
  5. 边爬边看：触发一次抓取，章节列表实时更新（依赖 SSE + nginx 关缓冲）。
  6. 排行榜、书架/搜索/我的、底部导航切换正常。
