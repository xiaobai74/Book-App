# 小说管理App — 后端测试计划 v1.1

> **测试版本**：v1.1 | **更新日期**：2026-08-03 | **测试环境**：http://localhost:8000

---

## 1. 测试概览

### 1.1 测试目标

基于项目 v1.1 版本的功能迭代，全面覆盖新增和变更的后端接口：

- **认证模块**（4 个接口）— 注册/登录/刷新/改密
- **书架模块**（4 个接口）— 列表/添加/详情/删除
- **搜索模块**（3 个接口）— 书架内搜索 / 外部源站搜索 / 源站列表
- **抓取与下载模块**（4 个接口）— 连通性检查 / 触发抓取 / 进度查询 / 文件下载
- **自定义源站模块**（6 个接口）— CRUD + 规则测试
- **系统接口**（1 个接口）— 健康检查
- **通用安全测试** — OWASP Top 10 / JWT / XSS / SQL 注入 / 授权

### 1.2 被测系统

| 组件 | 技术栈 | 地址 |
|------|--------|------|
| 后端 API | FastAPI + MySQL 8.0 + JWT | http://localhost:8000 |
| API 文档 | Swagger UI | http://localhost:8000/docs |
| 数据库 | MySQL 8.0 | localhost:3306/book |

### 1.3 版本变更（v1.0 → v1.1）

| 新增 / 变更 | 说明 |
|-------------|------|
| `GET /api/v1/search/external` | 外部源站搜索，支持指定源站或遍历所有源站 |
| `GET /api/v1/sources` | 获取全部可用源站列表（含自定义源站） |
| `POST /api/v1/crawl/check-url` | URL 连通性预检（HEAD 请求） |
| `GET /api/v1/books/{book_id}/download` | 支持 `?format=epub|txt` 双格式下载 |
| `GET /api/v1/crawl-sources` | 列出当前用户的自定义源站 |
| `POST /api/v1/crawl-sources` | 创建自定义源站规则 |
| `GET /api/v1/crawl-sources/{id}` | 获取单个自定义源站详情 |
| `PUT /api/v1/crawl-sources/{id}` | 更新自定义源站规则 |
| `DELETE /api/v1/crawl-sources/{id}` | 删除自定义源站规则 |
| `POST /api/v1/crawl-sources/test` | 测试自定义规则是否有效 |
| 通用回退 | 未匹配预配置规则的 URL 自动使用通用解析策略 |
| 数据库新增 | `crawl_sources` 表 |

### 2.4a 章节排序专项（SORT，v1.3.1 新增）— 单元测试 6 个用例

覆盖 `backend/app/services/crawler_service.py` 的 `sort_chapter_pairs` 与 `_chapter_sort_key`（对应 `test/test_crawler.py`）：

| 用例 ID | 场景 | 输入特征 | 预期结果 |
|---------|------|---------|---------|
| TC-SORT-01 | 卷重置保持原序 | 每卷 10 章、重复 3 卷（如《诛仙》） | 输出顺序与源站目录顺序完全一致 |
| TC-SORT-02 | 整页倒序纠正 | 目录按更新时间倒序（第31章→第1章） | 纠正为第1章→第31章升序 |
| TC-SORT-03 | 无序号条目固定 | 「序幕」位于首章之前 | 序幕保持在原位，后续章节正常排序 |
| TC-SORT-04 | 卷标题不参与比较 | 「第三卷 青云」+ 章节 + 「第四卷 迷局」+ 章节 | 卷标题与其后章节保持原顺序 |
| TC-SORT-05 | 中阿数字混合 | 「第一章」「第十章」「第11章」「第12章」 | 保持原顺序（第一章 < 第11章 判定一致） |
| TC-SORT-06 | 卷-章组合格式 | 「第5卷 第1章」…「第1卷 第2章」倒序 | 纠正为第1卷→第5卷升序，「第x卷 第y章」不被误判为卷标题 |

> **验收标准**：多卷小说（每卷从「第一章」重新计数）抓取后阅读顺序与源站一致；章节号中文/阿拉伯数字混合时从小到大；「序幕」「尾声」「新书广告」等无序号条目保持在原位置；EPUB/TXT 章节顺序与数据库 `index` 一致。
