# 小说管理App — 测试计划 v1.0

> **测试版本**：v1.0 | **创建日期**：2026-07-26 | **测试环境**：http://localhost:8000（后端）/ http://localhost:5173（前端）

---

## 1. 测试概览

### 1.1 测试目标

基于 **753 个 Anthropic Cybersecurity Skills** 中的 API 安全测试、Web 安全测试技能，对本项目进行全面安全与功能测试，覆盖：

- **OWASP API Security Top 10 (2023)** 对应的 API 安全风险
- **功能验收**（PRD §2 中的 12 条验收标准）
- **前后端集成正确性**

### 1.2 被测系统

| 组件 | 技术栈 | 测试地址 |
|------|--------|----------|
| 后端 REST API | FastAPI + MySQL + JWT | http://localhost:8000 |
| 前端 SPA | Vue 3 + Pinia + Element Plus | http://localhost:5173 |
| 数据库 | MySQL 8.0 | localhost:3306/book |

### 1.3 技能引用

本计划使用的安全测试技能（来自 Anthropic-Cybersecurity-Skills 库）：

| Skill | 覆盖领域 |
|-------|---------|
| `testing-api-security-with-owasp-top-10` | API1-API10 全覆盖扫描 |
| `conducting-api-security-testing` | REST API 认证/授权/输入/暴露面 |
| `testing-api-authentication-weaknesses` | JWT / Token / 密码策略 |
| `testing-jwt-token-security` | JWT 算法/密钥/声明攻击 |
| `testing-for-xss-vulnerabilities` | 反射/存储/DOM XSS |
| `testing-api-for-mass-assignment-vulnerability` | 属性批量绑定 |
| `testing-api-for-broken-object-level-authorization` | BOLA/IDOR |

| TC-AUTH-02 | POST /register | 重复邮箱注册 | 400, "该邮箱已注册" | api-auth |
| TC-AUTH-03 | POST /register | 密码无字母（纯数字） | 422, 验证失败 | api-auth |
