# 小说管理App — 前端测试计划 v1.1

> **测试版本**：v1.1 | **更新日期**：2026-08-03 | **测试地址**：http://localhost:5174

---

## 1. 测试概览

### 1.1 测试目标

基于项目 v1.1 版本的前端迭代，全面覆盖 7 个页面 / 8 个路由的功能、交互和兼容性：

- 路由守卫（8 条）
- 登录页（6 条）
- 注册页（6 条）
- 书架页（13 条）— 含新增的通用抓取提示
- 搜索页（6 条）
- 详情页（11 条）
- 设置页（5 条）
- **自定义源站管理页（12 条）— v1.1 新增**

### 1.2 被测系统

| 组件 | 技术栈 | 地址 |
|------|--------|------|
| 前端 SPA | Vue 3 + TypeScript + Vite + Pinia + Element Plus | http://localhost:5174 |
| 后端 API | FastAPI | http://localhost:8000 |

### 1.3 版本变更（v1.0 → v1.1）

| 新增 / 变更 | 说明 |
|-------------|------|
| `/crawl-sources` 路由 | 自定义源站管理页面 |
| `CrawlSourcesView.vue` | 新增：源站列表、添加/编辑弹窗、规则测试、帮助文档 |
| `ShelfView.vue` | 更新：添加书籍对话框文案提示"支持任意小说网站 URL" |
| `router/index.ts` | 新增 `/crawl-sources` 路由 |
| `types/index.ts` | 新增 `CrawlSource`、`CrawlSourceFormData`、`CrawlSourceTestRequest`、`CrawlSourceTestResult` 类型 |
| `api/books.ts` | 新增 6 个自定义源站 API 函数 |
