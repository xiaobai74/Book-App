# 小说管理App — 前端测试计划 v1.3

> **测试版本**：v1.3 | **更新日期**：2026-08-31 | **测试地址**：http://localhost:5173

---

## 1. 测试概览

### 1.1 测试目标

基于项目 v1.3 版本的前端迭代，全面覆盖 10 个页面 / 10 个路由的功能、交互和兼容性：

- 路由守卫（10 条）
- 登录页（6 条）
- 注册页（6 条）
- 书架页（22 条）— 含筛选、视图切换、长按操作、九宫格
- 搜索页（6 条）
- 详情页（13 条）— 含 AI 摘要、缓存优先加载
- 排行榜页（8 条）⭐ v1.3 新增
- 阅读器页（12 条）⭐ v1.3 新增
- 「我的」页（8 条）⭐ v1.3 新增
- **自定义源站管理页（12 条）**
- 全局组件（8 条）⭐ v1.3 新增（命令面板 / TabBar / 主题背景）

### 1.2 被测系统

| 组件 | 技术栈 | 地址 |
|------|--------|------|
| 前端 SPA | Vue 3 + TypeScript + Vite + Pinia + Element Plus | http://localhost:5173 |
| 后端 API | FastAPI | http://localhost:8000 |
