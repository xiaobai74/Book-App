## 4. 发现的问题与建议修复

### 🔴 问题 1：重复书名检查无效（HIGH）

**描述**：POST /api/v1/books 应检测同一用户书架中是否已有同名书籍并返回 409，但实际允许重复添加。

**修复建议**：`book_service.py` 的 `create_book` 方法应增加 `user_id + title` 唯一性检查。

### 🟡 问题 2：HTTP 状态码与 API 文档不一致（MEDIUM）

**描述**：
- 登录失败返回 401 而非文档声明的 400
- Token 缺失返回 422 而非 401（Pydantic 验证在认证中间件之前）

**修复建议**：统一异常处理层与文档声明的状态码。

### 🟡 问题 3：书籍已有抓取中状态时再次触发返回 409（MEDIUM）

**描述**：书籍已处于 crawling 状态时，再次 POST /crawl 返回 409 而文档未记录此状态码。

**修复建议**：文档中补充 409 错误码说明，与重复书名保持一致。
