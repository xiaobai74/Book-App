## 4. 发现的问题

| # | 严重程度 | 问题 | 建议 |
|---|---------|------|------|
| 1 | 🟡 MEDIUM | 外部源站搜索频繁超时（`GET /api/v1/search/external`） | 源站网络不稳或有限流；增加单源站超时时间或添加重试 |
| 2 | 🟡 LOW | 无 Token 返回 422 而非 401 | FastAPI Header 参数验证在认证中间件前执行 |
| 3 | 🔵 INFO | 根路径 URL 作为 source_url 时抓取失败（如 `biquh.com/`） | 建议前端提示用户输入具体的**目录页 URL**（如 `/book/123/`） |
| 4 | 🔵 INFO | `crawl-sources/test` 需目录页 URL（非首页） | 前端可在测试表单中添加 URL 格式说明 |
